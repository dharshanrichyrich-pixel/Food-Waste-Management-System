# Food Waste Management System — Frontend SPA

Responsive, modern Single Page Application built with React.js, Vite, and Tailwind CSS.

## Features
- **Role-Based Portals**: Tailored interfaces for Donors, Recipients/NGOs, Volunteers, and Admins.
- **AI Freshness & Matching Inspector**: Visual feedback on AI agent decisions, freshness scores, and match proposals.
- **Live Dispatch & Map Tracking**: Real-time delivery status and route visualization.
- **Impact Analytics Dashboard**: Real-time graphs for rescued meals, CO2 offset, and demand forecasts.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment:
   ```bash
   cp .env.example .env
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

Application will run at: `http://localhost:5173`
